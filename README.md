# Employee Attendance Tracker

A beginner Python project that calculates employee attendance percentage and determines attendance status.

## Features

- Accepts employee name
- Accepts days present
- Accepts total working days
- Calculates attendance percentage
- Shows attendance status
- Validates attendance input

## How to Run

Run the following command in the terminal:

python main.py

## Example

Employee: Hindu
Days Present: 18
Total Days: 20
Attendance: 90.0%
